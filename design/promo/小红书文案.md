## 正文（直接复制）

```
说个我用了十年才发现的事。

剪贴板只存最后一次复制的东西。
你复制新的，旧的立刻消失。

所以我经常：上午复制的一句话，下午想粘，没了。
然后开始翻文档、翻聊天记录、重新搜一遍。

后来装了个开源工具叫 Pastoid，逻辑特别简单：
按一下 ⌘⇧V，今天复制过的东西全摊在屏幕上。

🔹 文字、截图、链接自动分类
🔹 常用的可以钉住，永远排最前
🔹 方向键选、回车粘，手不用离开键盘

最爽的是它不打断工作流。
写代码的时候，终端里复制的命令，切到文档直接就能粘，不用回去翻终端历史。

免费、开源、无内购、也不收集数据。
Mac 和 Windows 都能用。

链接放评论区了，需要的自取 👇

你们有过「刚复制的东西找不到了」的瞬间吗？
```

## 发布设置

| 项 | 建议 |
|---|---|
| 类型 | 视频笔记 |
| 封面 | 用视频第 0.5 秒那帧（「找一个小时前复制过的东西」），别用默认首帧 |
| 时长 | 65 秒（小红书视频上限 15 分钟，这个长度完播率最稳） |
| 声音 | 保留配音 + 字幕，**别静音**——小红书的视频默认自动播放，有声更容易停住 |
| 时间 | 工作日 12:00–13:00，或 21:00–22:30 |
| 位置 | 可以带「北京·中关村」这类科技氛围的定位，会进同城流量池 |
| 评论区 | 发布后自己先置顶一条：「GitHub 搜 pastoid，或点这里 👉 链接」 |

---

## 发布后 30 分钟

1. 自己评论一条补充信息（GitHub 链接），并置顶
2. 回复前 5 条评论，把关键词再带一遍（「对，Mac 和 Windows 都有」）
3. 不要马上改标题，等 2 小时再看数据

**看什么**：首图点击率、3 秒完播率、收藏数。
收藏 > 点赞说明工具类内容被认可了，可以追一条「用了三天的感受」。
